# Airflow ETL Pipeline with MySQL Docker Setup

## Overview
This repository contains code and configuration files for an end-to-end ETL (Extract, Transform, Load) pipeline implemented using Apache Airflow. The pipeline extracts data from an OLTP database, performs transformations, and loads it into a data warehouse. Additionally, it executes dimensional queries and generates snapshots for reporting purposes.

## Features
- Automated ETL workflow orchestrated with Apache Airflow
- MySQL Docker containers used for both OLTP staging area and data warehouse
- Extract, Transform, Load operations for efficient data processing
- Dimensional queries execution for analysis
- Snapshot generation for reporting
